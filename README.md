### 🚀 No que eu trabalho

* 🤖 **Agentes de IA para atendimento** — triagem, roteamento entre agentes, *tool calling*, contexto de conversas e transferência para atendimento humano
* ⚙️ **Automação de processos empresariais** — desenvolvimento de scripts em **Python** para reduzir tarefas manuais e repetitivas
* 📊 **Automação de Excel e processamento de dados** — manipulação de planilhas, CSVs e dados com **Python, Pandas e OpenPyXL**
* 🔗 **Integração entre sistemas e APIs** — comunicação entre serviços, módulos internos e sistemas empresariais
* 🏢 **Sistemas corporativos** — desenvolvimento e integração de módulos internos e automações envolvendo **TOTVS Protheus**
* 🗄️ **Banco de dados** — consultas, modelagem e manipulação de dados utilizando **PostgreSQL e SQL**
* 🌐 **Aplicações web** — contato com desenvolvimento frontend e backend utilizando **React, Next.js, NestJS e APIs REST**
* ☁️ **Deploy e infraestrutura** — utilização de **Docker, Coolify, VPS, Cloudflare e Neon**
